Etiquetas HTML de formato

Etiqueta de énfasis

<em> Permite enfatizar un texto.

Etiqueta de marcado

<mark> Permite marcar un texto.

Etiquetas de encabezado

<hl> Permiten incluir encabezados en el documento

Etiqueta para indicar importancia de un texto

<strong> Permite marcar un texto importante.
